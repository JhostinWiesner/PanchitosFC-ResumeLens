# Pipeline Integration — Test Cases

| ID | Scenario | Input | Expected Result |
| -- | -------- | ----- | --------------- |
| TC-I01 | Extract and normalize known skills | Résumé containing `Python`, `Docker` and `Git` | `skills_raw` contains the original skill names; normalized tokens are `PYTHON`, `DOCKER` and `GIT`; `unrecognized` is empty. |
| TC-I02 | Preserve unrecognized terms during normalization | Résumé containing `Python`, `tecnologia_inventada_xyz` and `Docker` | Extraction preserves all three terms. Normalization produces `PYTHON` and `DOCKER`, while `tecnologia_inventada_xyz` is retained in `unrecognized`. |
| TC-I03 | Extract and normalize a résumé without a skills section | Résumé containing a name, email and professional summary, but no skills section | `skills_raw`, normalized `tokens` and `unrecognized` are empty lists. |
| TC-I04 | Normalize multiple known skills | Résumé containing `JavaScript`, `Python` and `PostgreSQL` | Extraction preserves the original names and order. Normalization produces `JAVASCRIPT`, `PYTHON` and `POSTGRESQL`, with no unrecognized terms. |
| TC-I05 | Successful end-to-end pipeline | Data Engineer résumé containing `Git`, `AWS`, `Airflow`, `Spark`, `PostgreSQL` and `Python` in a non-canonical order | The pipeline extracts and normalizes the skills, orders them as `PYTHON`, `POSTGRESQL`, `SPARK`, `AIRFLOW`, `AWS`, `GIT`, accepts the profile, builds the candidate and generates valid DSL and non-empty HTML output. |
| TC-I06 | Reject a résumé missing a required category | Data Engineer résumé containing `Python`, `PostgreSQL`, `Spark`, `AWS` and `Git`, without `Airflow` | The ordered sequence excludes `AIRFLOW`; classification and candidate evaluation are rejected; generated DSL and HTML indicate `REJECTED`. |
| TC-I07 | Preserve unknown skills and remove duplicate canonical qualifications | Data Engineer résumé containing `Python`, `python`, the required Data Engineer skills and `SkillInventadaXYZ` | Extraction preserves both Python variants and the unknown term. Normalization maps both variants to `PYTHON` and retains the unknown term in `unrecognized`. Ordering removes duplicate canonical qualifications, the candidate receives the ordered sequence, and classification is accepted. |
| TC-I08 | Serialize and render special characters | Data Engineer résumé with the summary `Builds "trusted" pipelines & <data>.` and all required skills | The summary is preserved in the extracted data and candidate. DSL output escapes quotation marks, and HTML output escapes quotation marks, ampersands and angle brackets. The profile is accepted. |
